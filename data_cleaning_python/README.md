# Uber Data Cleaning Project

This project demonstrates data cleaning techniques applied to a dataset of Uber customer reviews.

## Dataset Overview
The dataset contains:
- Missing values.
- Comments in multiple languages.
- Unnecessary columns.

## Key Steps
1. Removed unnecessary columns and handled missing values.
2. Standardized timestamps and text data.
3. Saved the cleaned dataset for further analysis.

## Tools Used
- Python (pandas, numpy)
- Jupyter Notebook
